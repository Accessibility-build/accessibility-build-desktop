# Changelog

Written from the user's point of view. Each release heading must read
`## <version> - <YYYY-MM-DD>`; `scripts/release.sh` refuses to build a
version without one.

## 1.0.0 - 2026-10-29

First release.

- Contrast picker: freeze every display, pick the text and background colors
  with a magnified loupe, by mouse or entirely by keyboard.
- WCAG 2.2 results for normal text, large text and UI components (1.4.3,
  1.4.6, 1.4.11), the APCA Lc value as guidance, the nearest passing colors,
  and the pair as four color-vision deficiencies may see it.
- Drag across an area while picking the background to use its
  lowest-contrast pixel.
- Color-vision lens with severity, blur, contrast loss and a split view.
- Captures of a region, the front window or a display, with an optional
  three-second delay, copied to the clipboard and savable as PNG.
- Session log with a Markdown export.
- Customizable global shortcuts, launch at login, and signed automatic updates.
